# P식 여행 시연 스크립트

## 1. 시연 전 준비

1. 터미널에서 프로젝트 루트로 이동한다.
2. `npm install`을 실행한다.
3. `npm run dev -- --host 127.0.0.1 --port 5173`을 실행한다.
4. 브라우저에서 `http://127.0.0.1:5173`에 접속한다.
5. 현재 버전은 프론트엔드 MVP이며 mock 데이터를 사용한다고 먼저 설명한다.

## 2. 정상 추천 시나리오

1. `/` 접속
2. 위치명에 `성수` 입력
3. 기분, MBTI, 인원 수, 이용 가능 시간을 간단히 확인
4. `추천 받기` 클릭
5. `/courses`에서 추천 카드 3개 확인
6. 첫 번째 카드 클릭
7. `/courses/:courseId` 상세 화면 확인
8. 코스 제목, 추천 이유, Leaflet + CARTO Positron 시연용 지도, 장소 순서, 이동 구간 설명
9. `목록으로 돌아가기` 클릭 후 `/courses` 복귀 확인

## 3. 빈 결과 시나리오

1. `/` 접속
2. 위치명에 `empty` 입력
3. `추천 받기` 클릭
4. `/courses`로 이동하는지 확인
5. 추천 결과 없음 EmptyState가 표시되는지 확인
6. 이 상태는 에러가 아니라 정상 응답이라고 설명한다.

## 4. 에러 시나리오

1. `/` 접속
2. 위치명에 `error` 입력
3. `추천 받기` 클릭
4. HomePage에 에러 메시지가 표시되는지 확인
5. `/courses`로 이동하지 않는지 확인

## 5. 직접 접근/새로고침 시나리오

1. `/courses`에 직접 접속하거나 새로고침한다.
2. 추천 응답 없음 EmptyState가 표시되는지 확인한다.
3. `/courses/test-id`에 직접 접속한다.
4. 추천 결과가 사라졌다는 EmptyState가 표시되는지 확인한다.
5. 추천 결과는 현재 세션 런타임 상태에만 저장된다고 설명한다.

## 6. 장소 제보 시나리오

1. `/places/report` 접속
2. 빈 상태로 `장소 제보하기` 클릭
3. 필수 입력 에러 표시 확인
4. 장소명, 카테고리, 주소, 추천 이유 입력
5. `장소 제보하기` 클릭
6. 장소 제보 완료 화면 확인
7. `새 장소 제보하기` 클릭
8. 폼이 초기화되는지 확인

## 7. 마이페이지 시나리오

1. `/mypage` 직접 접속
2. 최근 추천 없음 안내와 목업 통계 카드 확인
3. 정상 추천 시나리오를 한 번 수행한다.
4. `/mypage`로 이동한다.
5. 최근 추천 요약, 추천 결과 수, 추천 장소 수가 표시되는지 확인한다.
6. `장소 제보하러 가기` 클릭
7. `/places/report`로 이동하는지 확인한다.

## 8. 시연 시 강조할 점

- 현재는 프론트엔드 MVP이므로 mock 데이터를 사용한다.
- 추천 입력, 결과 목록, 상세, 장소 제보, 마이페이지 흐름을 한 번에 확인할 수 있다.
- 추천 결과는 localStorage가 아니라 Vue 런타임 상태에만 저장된다.
- 실제 API, 로그인, 운영용 지도 정책과 경로 탐색은 후속 단계에서 연결한다.
- 빈 결과와 에러 결과를 분리해서 처리한다.
