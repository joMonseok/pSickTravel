# P식 여행 1차 MVP QA 체크리스트

## 1. 실행/빌드

- [ ] `npm install` 성공
- [ ] `npm run dev -- --host 127.0.0.1 --port 5173` 실행
- [ ] `http://127.0.0.1:5173` 접속 가능
- [ ] `npm run build` 성공

## 2. 라우트 확인

- [ ] `/` 접속 가능
- [ ] `/courses` 직접 접근 시 추천 응답 없음 EmptyState 표시
- [ ] `/courses/:courseId` 직접 접근 시 추천 결과가 사라졌다는 EmptyState 표시
- [ ] `/places/report` 접속 가능
- [ ] `/mypage` 접속 가능
- [ ] 상단 네비게이션 링크 동작 확인

## 3. 추천 입력 화면

- [ ] 위치명 기본값 또는 입력값 표시
- [ ] 위치명이 비어 있으면 검증 에러 표시
- [ ] 인원 수가 1~10 범위를 벗어나면 검증 에러 표시
- [ ] 시작 시각이 비어 있으면 검증 에러 표시
- [ ] 반경이 1보다 작으면 검증 에러 표시
- [ ] 위치명 `성수` 입력 후 추천 요청 시 `/courses` 이동
- [ ] 위치명 `empty` 입력 후 추천 요청 시 `/courses` 이동
- [ ] 위치명 `error` 입력 후 추천 요청 시 HomePage에 에러 표시

## 4. 추천 결과 목록

- [ ] 추천 응답 없음 상태에서 EmptyState 표시
- [ ] empty 응답 상태에서 추천 결과 없음 EmptyState 표시
- [ ] 정상 응답 상태에서 추천 코스 카드 3개 표시
- [ ] 추천 조건 요약 표시
- [ ] 다시 입력하기 버튼으로 `/` 이동
- [ ] 카드 클릭 시 `/courses/:courseId` 이동

## 5. 코스 상세

- [ ] 추천 응답 없음 상태에서 EmptyState 표시
- [ ] 존재하지 않는 courseId에서 코스를 찾을 수 없음 EmptyState 표시
- [ ] 정상 courseId에서 코스 제목과 추천 이유 표시
- [ ] 총 소요 시간, 장소 수, 이동 구간 수 표시
- [ ] 코스 상세 화면에서 CARTO Positron 스타일 지도가 표시됨
- [ ] 장소 순서에 맞는 숫자 마커가 지도 위에 표시됨
- [ ] 마커 클릭 시 장소명 popup 표시
- [ ] 장소 순서 표시
- [ ] 이동 구간 표시
- [ ] 목록으로 돌아가기 버튼으로 `/courses` 이동
- [ ] 조건 다시 입력하기 버튼으로 `/` 이동

## 6. 장소 제보

- [ ] 빈 상태 제출 시 필수 입력 에러 표시
- [ ] 카테고리 선택 가능
- [ ] 추천 이유 300자 제한 표시
- [ ] 추가 메모 500자 제한 표시
- [ ] 필수 입력 후 제출 완료 상태 표시
- [ ] 새 장소 제보하기 클릭 시 폼 초기화
- [ ] 실제 저장이 되지 않는 목업 안내 표시

## 7. 마이페이지

- [ ] 추천 전 접속 시 최근 추천 없음 안내 표시
- [ ] 목업 통계 카드 표시
- [ ] 정상 추천 후 최근 추천 요약 표시
- [ ] 추천 결과 수 표시
- [ ] 최근 추천 장소 수 표시
- [ ] 추천 결과 보기 버튼으로 `/courses` 이동
- [ ] 다시 추천 받기 버튼으로 `/` 이동
- [ ] 장소 제보하러 가기 버튼으로 `/places/report` 이동

## 8. 모바일 화면

- [ ] HomePage 입력 폼이 1열로 표시
- [ ] CourseListPage 카드 목록이 1열로 표시
- [ ] CourseDetailPage 상세 레이아웃이 1열로 표시
- [ ] PlaceReportPage 폼이 1열로 표시
- [ ] MyPage 통계/콘텐츠 영역이 좁은 화면에서 깨지지 않음
- [ ] 헤더 메뉴가 좁은 화면에서 가로 스크롤 또는 줄바꿈으로 접근 가능

## 9. 미구현 범위 표시 확인

- [ ] 실제 API fetch가 연결된 것처럼 보이지 않음
- [ ] 지도는 Leaflet 기반 시연용 지도이며 운영용 지도 정책 검토가 필요함을 설명 가능
- [ ] 장소 제보는 실제 저장이 아니라 목업임이 표시됨
- [ ] 마이페이지 저장/제보 이력은 목업 상태임이 표시됨
- [ ] 새로고침 시 추천 결과가 사라지는 동작을 허용 범위로 설명 가능
